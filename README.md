# ArcaneTV 发布页

这里只放 ArcaneTV（Android TV 播放器）的安装包和更新信息，不包含源码。

## 下载
到 [Releases](https://github.com/apatan937/NextTGTV-Releases/releases) 下载最新版本：
- `ArcaneTV-版本-arm32.apk`：大多数电视 / 盒子用这个
- `ArcaneTV-版本-arm64.apk`：64 位的新电视可以用这个（更流畅）

安装过的 app 会每天自动检查一次更新（设置 › 关于 › 检查更新），也可以手动检查。
